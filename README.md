# 客服链接助手

Chrome / Edge Manifest V3扩展：按已选游戏显示飞书链接，保留筛选草稿，查询冠名资格，复制角色信息。

## 安装与数据

下载仓库源码并解压，在扩展管理页开启开发者模式，加载`extension`文件夹。

本仓库及安装包不包含业务链接库、默认飞书文档地址、玩家充值资料或个人授权信息。首次使用点击“数据管理”，填写自己的飞书多维表格或知识库地址，在同一浏览器登录有访问权限的账号后点击“立即刷新”。

支持“链接库_精简”（或“链接库”）和“游戏配置”两张表。链接数据、文档地址、成功缓存及共服设置只保存在使用者本机；更新代码不会清除它们。读取失败时可继续使用本机上次成功读取的缓存。没有首次成功读取记录的电脑不会得到任何内置业务链接。

## 更新

默认更新源为本仓库的默认分支、`extension`目录。启动浏览器及每6小时检查新版；有新版时显示图标和后台提示。点击“更新”→“检查并更新”，首次授权当前已加载的扩展文件夹，之后自动检查、下载、校验、备份、安装并重新加载。无需Releases或手动选择ZIP。

更新后刷新已打开的后台页。旧版没有此入口，需要手动加载一次支持更新的版本。系统可能要求再次授权目录；最近一次更新的原文件可在更新页恢复。

维护时修改`extension`中的代码，并提高`extension/manifest.json`的版本号后提交。同一版本号的代码提交不会触发新版提示。

## 更新页状态修复（1.12.1）

点击“检查并更新”发现新版后，状态立即显示“发现新版 x.x.x，正在处理”，安装过程中不再显示页面打开时的旧结果“当前已是最新版本”。

## 同步到链接库（1.12.0）

数据管理页“对比并同步到链接库”以客服资料大全为准，逐款游戏对齐“链接库_精简”。确认前逐款列出要新增、删除（原表已没有）的链接和专服变化，默认全部勾选，不想改的取消勾选后再点“确认写入”。

- 已一致的行不动；在原行上逐格修改，缺的行新增。
- 同一游戏的重复行、过时行标为“待核对”并在“核对说明”写明原因，不删除记录；插件不再使用这些行，确认后可在飞书按“状态 = 待核对”筛选删除。
- 原表改了游戏名称时，链接库和游戏配置原地改名，保留别名和后台游戏ID。
- 原表中跨几个版本合并的格子（同一后台、道具ID 覆盖几个版本），每个版本都会计入，专服只取本版本的行。
- 写入前复核：预览后有人改过某款游戏，整款跳过；每格写入前确认仍是旧值，不覆盖别人的修改；写后逐格读回核实，并可下载备份。

替代 1.11.x 的“对比并写入新增”、专服改名和人工确认卡片。更新重载后请关闭旧管理页并重新打开，确认顶部版本为 1.12.0。需要对链接库有编辑权限。

## 功能

- 未选游戏可以先填角色信息，切换游戏保留本页筛选草稿。
- gh3w5.17vipgame.com 后台“玩家日志”页新增“查询并导出 CSV”：直接按当前筛选条件查询，逐批写入本机选择的文件，不渲染大量结果行；表头随流水类型变化，支持取消。需要桌面 Chrome / Edge 的文件保存接口，更新后刷新后台页。使用前先用少量日志核对，真实大查询仍需公司电脑验收。
- 点击订单页、玩家页或冠名达标卡片的角色名，即复制该角色的`区服名称<Tab>角色名<Tab>角色ID`，可直接粘贴为同一行三列。没有额外文字按钮，悬停显示说明，复制后有短暂反馈。
- 数据管理页“同步客服资料大全”：填写原表飞书地址后，“对比并列出新增”只读列出链接库还没有的游戏和链接，按“名称 | 网址”整理好供复制粘贴；“对比并同步到链接库”确认后直接写入飞书（见上方 1.12.0）。
- 冠名按已支付订单的真实扣款金额、北京时间自然日核对。查询失败或不完整会明确提示；共服映射需确认。
- 更新中断时顶部提供修复入口；文件完整则补齐完成记录，未完成则恢复后重试。旧版按钮灰色时，先到页面底部“上次更新备份”恢复，再重新检查更新。
- 更新页可勾选自建加速线路（Cloudflare）并保存；仅按需申请update.cnszxyt.com访问权限，检查版本和下载文件均走加速，失败尝试直连。无需注册其他账号。
- 标签复用（原“网页标签复用助手”）：重复打开同一网页时切回已有标签；飞书和腾讯文档表格的另一个工作表在原标签内切换。开关、统计和整理已有重复页在“数据管理”页。需Chrome 121或更高版本；合并后请移除旧的“网页标签复用助手”。

## 权限

飞书站点用于读取当前浏览器已登录账号有权访问的文档；GitHub API和raw内容站点用于更新代码。剪贴板仅在点击复制按钮时写入，不读取剪贴板。更新目录写入须由使用者明确选择并授权。

玩家日志脚本仅在 gh3w5.17vipgame.com 的日志页及其同源 iframe 运行，使用当前登录态请求同一后台的查询接口，结果只写入使用者选择的本机 CSV，不上传到其他服务。

标签复用使用tabs和webNavigation比较标签网址、切换和关闭重复的新标签；scripting及飞书、docs.qq.com站点权限仅用于在已打开的表格中点击目标工作表标签。飞书页面另有两段内置脚本，只读取被点击链接的地址以便在点击时切换。均在本机完成，不读取文档正文，不收集或发送数据。

本仓库只分发运行代码和必要说明，不存放工作簿、业务快照、测试报告、截图、历史包或本机缓存。
